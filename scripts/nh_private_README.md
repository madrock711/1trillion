# NH PLUG 개인 확인 서버

이 프로그램은 현재 Windows 사용자 PC의 `127.0.0.1`에서만 열리는 임시 연마 화면이다. NH 앱키와 시크릿을 현재 Windows 계정의 DPAPI로 암호화해 `%LOCALAPPDATA%\Yeonma\nhplug.dpapi`에 보관한다. 키는 Git 저장소나 브라우저에 넣지 않는다. 로컬 서버 프로세스가 키를 이용해 24시간 토큰을 발급하고 만료 전 재사용하며, 토큰은 디스크에 저장하지 않는다. NH의 토큰 발급 보안 알림은 발생할 수 있다.

## 인증정보 등록과 실행

이 PC의 PowerShell에서 저장소로 이동해 아래 명령을 실행한다. `python`은 Python 3.9 이상이다. 최초 등록 시 앱키와 시크릿은 터미널에서 직접 입력하며 입력 글자는 화면에 나타나지 않는다. 키를 채팅에 붙여 넣지 않는다.

```powershell
python scripts/nh_private_server.py setup
python scripts/nh_private_server.py start
```

출력된 `http://127.0.0.1:포트/private-entry/...` 주소를 같은 PC의 브라우저에서 열고 해당 PowerShell 창은 켜 둔다. 주소에는 실행 중에만 유효한 임의의 개인 세션 값이 들어 있으므로 다른 사람에게 보내지 않는다. 종료는 `Ctrl+C`다. 닫았다 다시 열면 새 주소가 필요하다. 인증정보가 이미 있으면 `setup`은 덮어쓰지 않는다.

공식 NH PLUG SDK가 필요하며, 이전에 사용한 `nhplug-packages` 경로가 있으면 자동으로 사용한다. 그 경로가 없다면 실행 환경에 공식 `nhplug` 패키지를 설치해야 한다. SDK의 디스크 토큰 캐시는 이 프로세스에서 끈다.

## 자료의 상태

코스피 `통합(UNT)` 시간별 투자자 API에서 금액과 수량을 각각 요청하며 서버가 30초 동안 응답을 재사용한다. 2026-11-04 11:15 수량 응답은 사용자가 제공한 나무 화면의 개인·외국인·기관 수치와 일치했다. NH 문서에서 값의 단위와 시계열 필드의 거래일 해석은 명확하지 않아 원본 단위를 표시하고, 거래일은 장중 조회일로 추정한다. 응답의 `fetchedAt`은 **조회 시각**이며 거래 시각이 아니다. 가격은 KRX 정규장 기준이므로 통합시장 수급과 거래 범위가 다르다.

개인 서버는 임의의 브라우저 세션 쿠키와 같은 출처 검사로 개인 API에 접근한다. 공개 사이트나 외부 기기로 NH 시세를 제공하지 않는다. 이 서버는 가정용 PC의 다른 사용자나 악성 프로그램으로부터 완벽히 격리된 보안 경계는 아니다. 거래 주문 API는 구현하거나 호출하지 않는다.
