# 연마 애드센스 재검토 전 점검 — 2026년 9월 8일

## 판단 범위

사용자가 제공한 화면에는 ‘가치가 별로 없는 콘텐츠’와 2026년 9월 8일부터 검토를 다시 요청할 수 있다는 안내가 있다. 이 안내만으로 Google이 어느 URL의 어떤 문장을 문제 삼았는지는 알 수 없다. 아래 내용은 실제 사이트에서 확인한 결함과 개선 사항이며, Google 내부의 거절 사유를 확인했다는 뜻은 아니다. 승인 여부와 심사 기간은 보장할 수 없다.

Google은 독창적이고 유용한 콘텐츠와 명확한 탐색을 요구하며, 콘텐츠가 없거나 가치가 낮은 화면에는 광고를 허용하지 않는다. 확인한 공식 문서에는 ‘글 몇 편·몇 자·방문자 몇 명이면 승인’이라는 보장 기준이 없다.

- [AdSense 참여 요건](https://support.google.com/adsense/answer/9724?hl=ko)
- [사이트 페이지 준비 상태](https://support.google.com/adsense/answer/7299563?hl=en)
- [게시자 콘텐츠가 없는 화면 또는 가치가 낮은 화면](https://support.google.com/publisherpolicies/answer/11112688?hl=ko)
- [추가 가치 없는 복제 콘텐츠](https://support.google.com/publisherpolicies/answer/11190248?hl=en)

## 자동검사와 확인 범위

- 공개 HTML 64개, 연결된 로컬 자산 109개: 배포 허용 목록, 내부 링크 목적지, 페이지 안의 앵커, 중복 ID, canonical·사이트맵, 글 하단 이동 링크 검사.
- 홈·아카이브·시황: 실제 기사 파일과 목록의 일치, 최신순, 카테고리 수, JSON-LD, 첫 이미지 우선 로딩 검사. 특정 날짜나 고정 편수에 맞춘 검사를 실제 파일 기준으로 바꿨다.
- 검색: 복수 단어 동시 일치, 영문 대소문자, 빈 결과, 검색어 삭제, 카테고리와 검색의 조합 검사.
- Node 회귀 23개 통과. 브라우저에서 1280px 홈 46편, 390px 건강 목록 9편, 아카이브 시황 분류 31편과 검색 결과를 확인했다. 홈과 보완한 가이드 표에 화면 밖 가로 넘침이 없도록 검사했다.
- Amplify 빌드에 위 검사를 연결했다. 이는 링크와 구조 검사이지 내용의 정확성이나 독창성을 자동 판정하는 장치는 아니다.
- 변경 전 운영 사이트의 홈·가이드·최근 글·ads.txt·robots.txt는 정상 응답했고 임의의 없는 주소는 404였다. 인증 오류나 전체 본문 접근 차단을 주원인으로 볼 근거는 찾지 못했다.
- 46편 전체의 파일·구조는 검사했지만 모든 외부 출처와 모든 문장의 사실관계를 이번 작업에서 전수 검증한 것은 아니다. 건강·에세이·시황의 대표 글과 두 도구 가이드를 내용 점검 대상으로 삼았다.

## 유지한 것과 남은 일

자동 광고나 광고 슬롯을 추가하지 않았다. 기존 ads.txt, 사이트 소유 확인, 개인정보 안내와 통계 동의 절차를 유지했다. 글을 늘려 보이게 복제하거나 실제로 하지 않은 실험·사용 경험을 만들지 않았다. 이 문서는 내부 작업 기록이며 공개 배포 대상이 아니다.

몸과 마음 관련 최신 글이 시황보다 적다는 사실은 여전히 남는다. 다음 콘텐츠의 우선순위는 임의의 글 수 채우기가 아니라, 실제 호흡·그립 측정에서 나온 질문과 관찰을 조건·기록·변화와 함께 설명하는 것이다. 개인정보와 당사자의 공개 동의를 확인한 실제 기록이 생겼을 때 다룬다. 이번 가이드의 수치는 계산과 기록 방법을 설명하는 가상 예시다.

재검토는 배포된 페이지를 확인한 뒤 AdSense에서 다시 요청한다. 이번 작업은 사이트 수정과 검증이며, 계정의 ‘문제를 수정했음’ 체크나 검토 요청 제출은 수행하지 않는다. 승인되어도 광고의 위치와 수량은 별도 결정해야 한다.
