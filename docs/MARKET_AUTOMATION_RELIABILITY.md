## 적용 절차

- 예약 작업은 기존 모델과 평일 08시 일정을 유지하고 reasoning effort를 high로 변경한다. 설정을 재조회한다. 이 변경은 품질 개선 조치이며 장기 실행을 보장하는 타임아웃 설정이 아니다.
- 시작과 최종 응답 전에 `python scripts/check_market_run.py --date YYYY-MM-DD`를 실행한다. exit 2와 decision=continue는 남은 단계를 계속하라는 뜻이다. 실제 오류가 없는 상태에서 incomplete로 기록하고 종료하지 않는다.
- 단계 완료 직후 실제 시각과 산출물 경로를 상태에 기록한다. 첫 원천 요청 실패는 승인된 재시도나 대체출처로 복구한다. 복구 성공 뒤에는 다음 단계를 진행한다.
- 매일 임시 collect/build/seal/verify 코드를 새로 만드는 데 시간을 쓰지 말고 검증된 도구를 우선 사용한다. 재사용 시 날짜·시장상태·제목·각 카드 이미지 연결을 대조한다. 기사 이미지를 전역 치환하지 않는다.
- 로컬 검사 exit 0은 증거 존재 확인이다. 완료 보고는 원격 main SHA, 최종 Amplify SUCCEED의 commit SHA, 두 도메인 cache-busted 기사·자산의 Git 바이트 일치, 브라우저 확인까지 대조한 뒤에만 한다.
- 공식 휴장/실제 차단은 별도 증거와 대안 시도·오류·시각·재개 지점을 기록한다. 검사 실패 자체를 외부 차단으로 사용하지 않는다.
