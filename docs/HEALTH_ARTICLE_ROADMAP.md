# 건강정보 아티클 로드맵: 의식·영성·명상을 근거 중심으로 읽기

## 번호와 상태 규칙

- `HC-###`는 전체 목차의 고정 콘텐츠 ID다. **연재 n편은 HC 번호만 뜻한다.** 예: 연재 2편 = `HC-002`.
- `PUB-###`는 실제 배포 이력을 기록하는 ID다. 독자에게 연재 번호로 표시하지 않는다.
- 작성 큐의 `우선순위`는 작업 순서이며 바뀔 수 있다. 제목만 쓰지 않고 항상 `HC-###`를 함께 쓴다.
- 상태는 `backlog`, `research-ready`, `queued`, `drafting`, `published`, `private-draft` 중 하나를 사용한다.
- 공개 URL과 사이트맵에는 `published` 콘텐츠만 넣는다. `private-draft`는 `docs/drafts/`에 보관하고 Amplify 배포 대상에서 제외한다.

## 기획 원칙

- 첨부 이미지의 독서·탐구 주제는 콘텐츠의 출발점으로만 사용하고, 건강 효과의 근거로 사용하지 않는다.
- 종교·철학·개인의 영적 경험은 역사적 의미, 주관적 경험, 검증 가능한 건강 주장으로 나누어 설명한다.
- `치유`, `재프로그래밍`, `뇌 재배선`, `주파수 상승`, `정화`처럼 치료 효과로 읽힐 수 있는 표현에는 연구 조건과 한계를 함께 표시한다.
- 건강·정신건강 글은 일반 정보임과 의료 전문가의 검수 여부를 밝히고, 필요한 경우 상담·진료 기준을 제공한다.
- 핵심 키워드는 제목·첫 문단·주요 소제목에 자연스럽게 사용하며 반복 문구로 채우지 않는다.
- 후속 글이 실제 발행되기 전에는 빈 내부 링크를 만들지 않는다. 발행 시 앞뒤 글을 상호 연결한다.
- 대조형 방어 문장을 연속해서 사용하지 않는다. 독자가 실행하거나 확인할 수 있는 내용을 먼저 서술한다.
