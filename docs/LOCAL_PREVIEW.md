# 로컬 미리보기와 제작관리 서버 분리

연마 미리보기는 저장소 루트에서 `python scripts/preview_site.py`로 실행한다.
출력된 주소를 사용하고, 검증 후 Ctrl+C로 종료한다. 실행 위치와 무관하게
이 저장소를 제공하며 OS가 배정한 빈 포트에만 바인딩한다.

`8765`는 HpMpshorts 제작관리 서버 전용이다. 연마 확인에
`python -m http.server 8765`를 사용하지 않는다. Windows에서는 기존
와일드카드 리스너와 루프백 리스너의 주소 재사용으로 요청이 다른 서버에
도달할 수 있다. 미리보기 서버는 Windows 독점 바인딩도 적용한다.

2026-09-11 연마 발행 검증 중 같은 포트를 사용해 제작관리 API 요청이
연마 정적 서버에서 404로 처리됐다. 임시 서버 종료 후 포트 소유자는
HpMpshorts `manager/server.py`이며 제작관리 로그인 HTTP 200을 확인했다.
이 사건은 로컬 포트 충돌이며 공개 Amplify 배포와 별개다.
