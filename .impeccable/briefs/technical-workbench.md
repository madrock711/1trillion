# 기술적 분석 고급 도구 확장

Mode: Operate
Artifact: articles/market.html#technical-workbench
Scope: 기존 시황 대시보드 안의 고급 차트 기능. 기존 화면과 배색을 유지한다.

## Direction contract

THESIS: 기술적 분석 사용자가 동일 OHLCV를 바탕으로 매물대·추세·시간봉을 함께 확인하고 과거 시점의 판단을 재생한다. 실제 계산과 사용 흐름이 완성 기준이다.

OWN-WORLD: 기존 검정·녹색 시장 대시보드, 한글 산세리프, 작은 둥근 폼 컨트롤과 가는 경계선을 이어 쓴다. 캔들 상승은 기존 국내시장 관례의 빨강, 하락은 파랑, VWAP·POC는 황색, 추세는 녹색이다. 별도 브랜드나 장식은 추가하지 않는다.

STORY: 종목과 원본 봉을 고른 다음 지표를 겹치고, 시간 단위를 비교하고, 과거 봉을 재생한다. 필요한 가격선을 그리거나 원본 봉 조건 알림을 저장하고 CSV를 내보낸다.

FIRST VIEWPORT: 기술적 분석 제목 다음에 고급 차트가 온다. 제목과 내보내기, 종목·봉 설정, 지표, 그리기, 값 읽기, 가격·거래량·보조 지표, 재생 조작 순서다. 세부 알림과 설정은 아래 접힌 영역에 둔다.

FORM: 기존 기능 화면의 확장, 코드 기반 SVG 차트. 핵심 동작은 재생 시점까지의 원본 봉을 먼저 자른 뒤 모든 집계·지표를 다시 계산하는 것이다. 자동 재생만 상태를 변화시키며 장식용 모션은 없다.

FINISH: 데스크톱·모바일과 수치·상태 테스트, 별도 코드·화면 검토, 한국어 사용 문서까지 완료한다. 기존 시각 체계를 보존하며 신규 이미지·새 디자인 시스템은 만들지 않는다.
