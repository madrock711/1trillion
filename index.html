훈련·측정 도구

각 카드는 실행 화면과 설명 문서를 분리해 연결합니다. 실행 화면은 조작에 집중하고, 가이드는 기본값의 근거·실패 조건·안전 범위를 JS 없이도 읽을 수 있게 구성했습니다.

클라이밍 측정

아브라행·맥스행

WH-C06 크레인 저울과 연결해 좌우 3회 측정을 교대 수행하고, 1초 피크·200ms 힘·90% 유지·출력 감소율을 기록합니다.

  • 저강도 아브라행과 최대 힘 측정을 분리
  • 측정 정의와 샘플 부족 조건을 명시
  • 기록은 브라우저 로컬 저장소에 보관

  • 들숨·날숨 동기화와 개별 설정
  • 설정값만 로컬에 보존하고 세션은 저장하지 않음
  • 불편·어지러움 발생 시 중단 기준 제공

코드와 설명 일치

가이드의 시간·계산식·저장 범위를 실제 구현과 대조합니다. 기능이 바뀌면 관련 문서의 검증 날짜도 함께 갱신합니다.

근거와 설계값 구분

외부 연구에서 가져온 사실, 앱이 선택한 기본값, 기기 제약에서 추론한 값을 같은 근거처럼 섞지 않습니다.

재현 가능한 예시

입력→계산→표시 과정을 예시로 남기고, 샘플 부족·권한 거부·파일 호환 실패처럼 결과가 나오지 않는 조건도 적습니다.

과장하지 않는 한계

저울로 자세를 판별하거나, 사진으로 발 치수를 자동 측정하거나, 과거 번호로 다음 추첨을 예측한다고 표현하지 않습니다.
