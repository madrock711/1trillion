# 한국어 윤문 회귀 사례

정답 문장 하나를 외우지 않는다. 각 사례의 보존 조건과 실패 조건으로 평가한다.

## 하드 게이트

- 원문의 사실, 수치, 주장 강도와 문구의 역할이 바뀌지 않는다.
- 원문에 없는 원인, 효과, 방법을 만들지 않는다.
- 뜻을 확정할 근거가 없으면 유창한 문장으로 임의 완성하지 않는다.
- 카드·검색 요약에는 실제 글의 내용 대신 제작자용 운영 메모를 내세우지 않는다. 절차가 본문인 방법론·정정문·투명성 보고서는 예외다.
- 사용자 교정도 맞춤법, 호응, 중복과 의미 변경을 다시 점검한다.

## 고정 평가 사례

각 원칙은 긍정 사례(A)와 과잉 적용을 막는 반례(B)를 함께 통과해야 한다. 허용 출력은 한 문장으로 고정하지 않고 `필수 행동`과 `금지 변경`으로 판정한다.

### `HK-01A` 실제 쓰임

- 입력: `사용자 신뢰를 적립합니다.`
- 필수 행동: 문구의 목적과 문맥을 확인하고, 일반 문구라면 익숙한 결합으로 고친다.
- 금지 변경: 구체적 근거 없이 신뢰가 높아진다고 단정하지 않는다.

### `HK-01B` 전문 용어 반례

- 입력: `전송 전에 영상 데이터를 압축합니다.`
- 필수 행동: 기술적 의미의 `압축`을 유지한다.
- 금지 변경: 모든 추상어를 풀어야 한다는 이유로 표준 용어를 바꾸지 않는다.

### `HK-02A` 모호한 압축

- 입력: `날짜보다 반복 기회와 시작 노력을 기록합니다.`
- 필수 행동: 비교 기준과 두 추상명사의 뜻을 확인한다.
- 금지 변경: 관찰 보고를 중요도 판단으로 임의 변경하지 않는다.

### `HK-02B` 에세이 단문 반례

- 입력: `관찰이 쌓여 답으로 향한다.`
- 필수 행동: 앞뒤 문맥에서 뜻이 복원되면 단문을 보존한다.
- 금지 변경: 설명문처럼 늘이거나 인과를 더 강하게 만들지 않는다.

### `HK-03A` 대상 없는 추상명사

- 입력: `중단 신호와 조건을 기록합니다.`
- 필수 행동: 무엇의 중단 신호와 어떤 수행 조건인지 문맥에서 확인한다.
- 금지 변경: 원문에 없는 통증 종류나 측정 환경을 지어내지 않는다.

### `HK-03B` 화면 문맥 반례

- 입력 문맥: `맥스행 측정` 제목과 `수행 조건` 입력란 바로 아래 도움말 `조건을 기록합니다.`
- 필수 행동: 화면이 대상을 이미 보여주면 짧은 문구를 유지할 수 있다.
- 금지 변경: 모든 화면 정보를 도움말 안에 되풀이하지 않는다.

### `HK-04A` 운영 메모

- 입력: 홈 카드 소개 `수치와 전망을 분리하고 다음 관찰에서 틀렸는지 확인할 조건을 남겼습니다.`
- 필수 행동: 실제 글 내용이 있으면 별도 카피 편집 범위에서 대표 관찰을 고르고, 없으면 질문하거나 보류한다.
- 금지 변경: `정직하게`, `명확하게`, `신뢰할 수 있게` 같은 홍보 효용으로 포장하지 않는다.

### `HK-04B` 방법론 반례

- 입력 문맥: 연구 방법 페이지 `측정값과 해석을 분리해 기록합니다.`
- 필수 행동: 절차 자체가 본문이므로 보존하거나 표면만 다듬는다.
- 금지 변경: 공개된 절차라는 이유만으로 삭제하거나 관찰 결과로 바꾸지 않는다.

### `HK-05A` 표제

- 입력: 섹션 표제 `측정, 해석, 한계를 한곳에 둡니다.`
- 필수 행동: 문맥상 병렬 개념을 소개하는 표제라면 자연스러운 명사구를 허용한다.
- 금지 변경: 만능 동사를 새로 붙이지 않는다.

### `HK-05B` 행동 안내 반례

- 입력: 버튼 레이블 `저장`
- 필수 행동: 구체적인 행동이 분명하면 그대로 둔다.
- 금지 변경: 대상·효용·근거를 모두 넣은 완전문으로 늘이지 않는다.

### `HK-06A` 확인된 방법 정정

- 입력 문맥: 원문 `4초 들숨 · 6초 날숨`, 사용자가 현재 기초법은 들숨과 날숨을 같은 길이로 한다고 정정.
- 필수 행동: 사용자의 새 방법 전제를 반영한다.
- 금지 변경: 기존 수치를 원래 주장이라는 이유로 보존하지 않는다.

### `HK-06B` 검증되지 않은 명칭 반례

- 입력 문맥: 사용자가 특정 호흡법의 역사적 명칭을 함께 언급했지만 조사 요청은 하지 않음.
- 필수 행동: 시간 원칙과 역사적 명칭 주장을 분리한다.
- 금지 변경: 명칭과 기원을 독립 검증 없이 일반 사실로 확대하지 않는다.

### `HK-07A` 중복 교정

- 입력: `최고 기록보다 중요한 것은 수행 조건과 회복 시간을 기록하는 것이 중요합니다.`
- 필수 행동: 중요도 판단을 유지하면서 `중요한 것은 … 중요합니다` 중복을 없앤다.
- 금지 변경: 중요도 판단을 단순 관찰 보고로 되돌리지 않는다.

### `HK-07B` 짧은 경고 반례

- 입력: `아프면 멈춥니다.`
- 필수 행동: 문맥상 충분하면 짧고 단정한 경고를 보존한다.
- 금지 변경: 사유와 예외를 임의로 덧붙여 장황하게 만들지 않는다.

## 패턴 설명

### 사례 1 · 낯선 명사 결합 (`HK-01`)

- 입력 성격: 짧은 섹션명에 일상적으로 잘 결합하지 않는 한자어 명사 두 개가 붙어 있다.
- 통과: 기존 분야 용어인지 확인하고, 아니라면 익숙한 표제나 구체적인 활동명으로 바꾼다.
- 실패: 짧고 그럴듯하다는 이유로 새 이름을 그대로 유지하거나 또 다른 조어로 바꾼다.
- 예외: 프로젝트가 이미 정의해 꾸준히 쓰는 고유 명칭.

### 사례 2 · 모호한 비교 (`HK-02`)

- 입력 성격: 날짜와 수행 기회처럼 층위가 다른 대상을 `A보다 B`로 비교한다.
- 통과: 무엇을 비교하는지 밝히고, 원문이 변화 기록인지 중요도 판단인지 보존한다.
- 실패: 자연스럽게 보이도록 고치면서 관찰 보고를 가치 판단으로 바꾼다.

### 사례 3 · 방법의 전제 충돌 (`HK-06`)

- 입력 성격: 문장은 매끄럽지만 수치나 절차가 프로젝트의 핵심 방법과 다르다.
- 통과: 문체 편집을 멈추고 현재 문맥에서 방법을 확인한다. 확인된 원칙만 정확히 쓴다.
- 실패: 제시된 숫자를 그대로 살려 더 유창한 잘못을 만든다.

### 사례 4 · 명사구와 완전문 (`HK-05`)

- 입력 성격: 세 개의 병렬 개념을 소개하는 짧은 표제다.
- 통과: 표제라면 자연스러운 명사구를 허용한다. 본문이라면 주어와 서술어가 호응하는 완전문을 쓴다.
- 실패: 모든 문구에 `한곳에 둔다`, `함께 살핀다` 같은 만능 동사를 붙인다.

### 사례 5 · 추상명사 풀기 (`HK-03`)

- 입력 성격: `기회`, `조건`, `신호`의 대상이 문장만으로는 드러나지 않는다.
- 통과: 무엇을 할 기회인지, 어떤 조건인지, 무엇이 중단 판단을 일으켰는지 필요한 만큼 밝힌다.
- 실패: 모든 명사를 긴 관형절로 바꿔 뜻을 중복하거나 원문에 없는 상세를 만든다.

### 사례 6 · 제작자용 운영 메모의 공개 노출 (`HK-04`)

- 입력 성격: 카드 한 줄 소개가 수치 분리, 검증 방식, 집필 절차만 보고한다.
- 통과: 원문이나 본문에 실제 관찰·판단이 있으면 별도 카피 편집 범위에서 대표 내용을 다시 고른다. 근거가 없거나 표면 윤문만 요청받았다면 임의로 교체하지 않고 질문하거나 보류한다.
- 실패: 작업 절차를 `정직하게 살펴본다`, `명확하게 보여 준다`, `독자가 안심할 수 있게 한다` 같은 홍보 문구로 포장한다.
- 예외: 방법론, 검증 보고서, 정정 기록처럼 절차 자체가 본문인 글.

### 사례 7 · 사용자 교정의 재검토 (`HK-07`)

- 입력 성격: 사용자 교정이 의도를 잘 드러내지만 같은 판단어를 되풀이하거나 띄어쓰기 오류를 포함한다.
- 통과: 사용자의 의도를 보존하면서 중복과 문법을 바로잡는다.
- 실패: 사용자 문장을 글자 그대로 복사하거나, 반대로 사소한 문법 오류를 이유로 핵심 지적을 무시한다.

## 추가 고정 회귀 사례

아래 문장은 고정 회귀 입력이다. 새 원칙을 평가하는 전방 입력은 이 파일 밖에서 만들고, 실행 뒤에만 기록한다.

1. `선택의 여백을 축적합니다.` — 실제 행동이나 결과가 무엇인지 확인한다.
2. `사용자 신뢰를 적립합니다.` — 문법만 맞는 어색한 연어를 실제 한국어 결합으로 고친다.
3. `근거와 판단을 분리해 독자가 안심하도록 구성했습니다.` — 공개 요약인지 편집 보고인지 구분한다.
4. `전송 전에 영상 데이터를 압축합니다.` — 전문적 의미의 `압축`을 금칙어처럼 풀지 않는다.
5. `아프면, 멈춥니다.` — 짧고 개성 있는 문장을 장황하게 늘리지 않는다.
