# 일일 시황 썸네일 방향

## 시각 논제부터 정한다

이미지 생성 전에 다음 네 항목을 한 줄씩 적는다.

1. 오늘의 주도 사건 1~2개
2. 시장 방향과 변곡점
3. 독자에게 남길 감정: 경계, 안도, 긴장, 회복, 불확실성 중 하나
4. 사건에 맞는 색과 빛

이 네 항목이 이미지 프롬프트의 출발점이다. 이전 썸네일 파일은 생성 참조 이미지로 넣지 않는다.

## 밝기와 색

- 부정적 장세도 무조건 검정 배경과 붉은 하락선으로 만들지 않는다.
- 위기 자체보다 `매도 물량의 이동`, `공급 부족`, `반등 조건`처럼 그날 고유한 사건을 시각화한다.
- 중간톤이나 밝은 배경, 자연광, 하늘색·청록·아이보리·금색·산호색 등 읽기 쉬운 색을 적극 사용한다.
- 실제 긴급 충격을 표현해야 할 때만 어두운 톤을 쓰며, 어둠이 화면 대부분을 차지하지 않게 한다.
- 최근 이미지와 같은 소재·구도·주조색을 연속해서 반복하지 않는다. 기존 이미지는 중복 여부를 확인하는 용도로만 본다.

## 구성과 출력

- 글자, 숫자, 로고, 워터마크를 넣지 않는다.
- 1200×630, 가로형, 모바일 카드 중앙 크롭에서도 핵심 피사체가 남는 구도로 만든다.
- 이미지 한 장에 사건을 과도하게 나열하지 말고 주도 사건 하나와 보조 신호 하나만 결합한다.
- 생성 뒤 실제 아티클 목록의 데스크톱·모바일 크기로 확인한다.
- 대표 이미지 설명은 독자가 사건을 이해하도록 쓰고, 생성 방식이나 내부 편집 지시는 공개하지 않는다.
