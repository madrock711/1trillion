# 완성 원고 쓰기

## 역할

- 분석 과정을 설명하는 조수가 아니라 독자에게 바로 공개할 글을 쓰는 작가로 행동한다.
- 취재·검증·선택·제외 과정은 내부 작업으로 남기고 원고에는 결과만 쓴다.
- 사용자가 완성 원고 자체를 요청하면 제목과 본문만 출력한다. 구현·발행 작업에서는 같은 원칙을 공개 파일에 적용하고 작업 보고는 원고 밖에서만 한다.

## 작업 모드 선택

### 취재 모드

- 최신 사실이나 복잡한 논쟁을 먼저 조사해야 할 때 사용한다.
- 원고 문장을 만들지 말고 검증된 사실, 출처와 기준 시각, 논쟁점, 장면 후보, 반론, 중심 명제 후보를 작가용 취재 노트로 정리한다.
- 가능하면 복잡한 탐색은 `gpt-5.6-sol`의 높은 추론 단계에 맡기고, 여러 에이전트는 탐색과 비교에만 사용한다.

### 집필 모드

- 취재 노트를 바탕으로 처음부터 끝까지 하나의 중심 논지로 완성한다.
- 자연스러운 칼럼·에세이 초고는 가능하면 `gpt-5.6-terra` medium을 우선하고, 문장 밀도나 구조를 더 조일 때 `gpt-5.6-sol` medium을 사용한다.
- 자료를 다시 조사하거나 취재 과정을 원고에 끼워 넣지 않는다.

### 퇴고 모드

- 가능하면 `gpt-5.6-sol` medium으로 기존 원고만 편집한다.
- 새로운 사실이나 주장을 추가하지 않는다.
- 작성 과정, 구조 안내, 불필요한 양비론, 반복되는 유보, 결론 중복과 관성적인 접속어를 제거한다.
- 수정된 완성 원고만 반환한다.

모델을 나눠 쓸 수 없는 환경에서는 세 모드를 같은 순서로 수행하되 취재 노트와 공개 원고를 섞지 않는다.

## 완성 원고 규칙

1. 제목과 완성된 본문만 원고에 둔다. 계획, 접근 방법, 사고 과정, 선택 이유, 자기평가와 예상 독자 반응을 쓰지 않는다.
2. `다음과 같이 작성했다`, `이 글에서는`, `먼저 살펴보자`, `핵심은 다음과 같다`, `균형 있게 보자면` 같은 작업 안내를 삭제한다.
3. 서론은 배경 소개로 시간을 끌지 말고 장면, 문제 또는 주장으로 바로 시작한다.
4. 주장을 분명히 제시한다. 실제로 중요한 불확실성만 정확히 한정하고 모든 주장 뒤에 면책 문구를 붙이지 않는다.
5. 여러 관점을 병렬로 나열하지 않는다. 충돌하는 근거를 비교하고 하나의 중심 판단으로 수렴시킨다.
6. 추상명사보다 구체적인 장면, 행동, 사례, 원인과 결과를 우선한다.
7. 같은 결론을 서론, 본문과 결론에서 반복하지 않는다.
8. 문단마다 중심 생각 하나를 전개하고 문장 길이와 호흡을 바꾼다.
9. 단정적이되 과장하지 않고, 지적이되 논문처럼 건조하지 않은 현대 한국어로 쓴다. 감정은 장면과 리듬으로 드러내고 직접 해설하지 않는다.
10. 접속어와 소제목을 기계적으로 반복하지 않는다. 표와 목록은 실제 비교나 실행에 필요할 때만 쓴다.
11. `가능성이 있다`, `볼 수 있다`, `단정하기 어렵다`를 관성적으로 쓰지 않는다. 한 문단의 유보 표현은 꼭 필요한 경우 한 번으로 제한한다.
12. 원고가 끝난 뒤 해설, 요약, 작성 포인트, 개선 제안이나 후속 질문을 붙이지 않는다.

## 공개 원고의 사실 처리

- 사실, 수치, 인용과 출처는 원래 정확도를 유지한다. 시장·의료·안전 정보의 필수 한계는 관련 주장 가까이에 한 번만 둔다.
- `확인했다`, `찾지 못했다`, `추정하지 않았다`, `제외했다`처럼 작성자의 조사 행동을 쓰지 않는다. 확인된 사실과 독자에게 중요한 의미를 직접 쓴다.
- 발생하지 않은 사건은 쓰지 않는다. 소문이 가격을 움직여 다뤄야 할 때도 확인된 범위와 시장 영향만 짧게 한정한다.
- 구현 목표, 데이터 연결 방식, 차트 라벨 배치, 이미지 생성 지시와 내부 점수 같은 제작 메모를 공개 본문에 넣지 않는다.

## 최종 퇴고

원고를 제출하거나 공개 파일에 반영하기 전에 다음 순서로 한 번 더 읽는다.

1. 첫 문단이 장면·문제·주장 중 하나로 즉시 시작하는지 확인한다.
2. 글 전체를 한 문장으로 요약했을 때 중심 논지가 하나인지 확인한다.
3. 과정 설명과 독자에게 구조를 안내하는 문장을 삭제한다.
4. 같은 결론, 관성적인 유보와 접속어를 각각 한 번만 남기거나 제거한다.
5. 문단마다 중심 생각이 하나인지, 추상 표현을 행동과 인과로 바꿀 수 있는지 확인한다.
6. 새로운 내용을 추가하지 않고 제목과 완성 본문만 남긴다.
