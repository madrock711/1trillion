# 장 마감 결과

전망 원본을 수정하지 않고 같은 `forecastId`의 판정 JSON을 별도로 둔다. `actualRef`로 해당 거래일의 공통 실제값을 가리키고, 봉인된 조건 전체의 관측값·주요 원인 판정·고정 오류 코드·가설 검증 결과를 기록한다. 평가기는 조건별 상태와 시나리오 AND·OR를 다시 계산해 트리거 오탐·미탐을 자동 부여한다. 가설의 후보·기준 예측값, predictor 판본과 시장 국면은 전망의 `hypothesisTrials`에서만 읽으며 결과 파일에 사후 추가하지 않는다. 장중판은 `postForecastPathStatus`를 반드시 기록하며, 경로가 없으면 `missing`과 누락 사유를 남기고 추정하지 않는다.

경로를 확보하지 못한 장중판은 자유 문장만 남기지 않고 `postForecastPathMissingEvidence`에 원천 상태·출처·종가 기준 시각·수집 시각·원문 해시를 기록한다. 평가기는 확인된 경로 적중률과 함께 누락이 모두 적중한 최선값, 누락이 모두 실패한 하한을 계산하며 활성 판단에는 coverage gate를 통과한 하한만 쓴다.

수급 가설은 결과 파일에 사후 입력값을 쓰지 않는다. 평가기가 전망의 `predictorInputs`와 공통 실제값의 같은 `flowTrajectory` 앵커를 대조하고, 필요한 변화량·지속성 feature를 계산한다. 입력이나 실제 앵커가 없어도 표본을 삭제하지 않고 증거 상태와 커버리지에 반영한다.

필수 필드와 검증 규칙은 `docs/KOSPI_RESEARCH_EVALUATION.md`를 따른다.
