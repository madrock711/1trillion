연마 소개

연마는 사용자가 직접 반복 훈련과 제작 작업을 관리할 수 있도록 만든 웹 도구 모음입니다. 호흡, CO2 테이블, 아브라행 행보드, 암벽화 핏 자가 점검처럼 기록과 기준이 중요한 작업을 브라우저 안에서 바로 실행할 수 있게 구성했습니다.

운영 원칙

연마는 짧은 유행성 문구보다 실제 사용 흐름을 우선합니다. 타이머는 시작과 종료가 명확해야 하고, 기록은 사용자가 나중에 다시 읽을 수 있어야 하며, 훈련 도구는 안전 기준과 한계를 함께 보여 주어야 합니다.

이 사이트의 콘텐츠는 도구를 설명하기 위해 작성한 원본 문서입니다. 외부 논문이나 공식 자료를 참고한 경우에는 해당 출처를 밝혀, 사용자가 근거와 한계를 직접 확인할 수 있도록 합니다.

현재 제공하는 도구

  • 호흡 타이머: 들숨과 날숨 리듬을 시각/청각 신호로 따라가는 도구
  • CO2 테이블 타이머: 숨참기와 휴식 감소 패턴을 기록하는 도구
  • 아브라행 행보드 타이머: 저강도 손가락 로딩과 회복 시간을 관리하는 도구
  • 암벽화 핏 점검: 좌우 발 실측값과 형태 자가 체크를 착화 질문으로 정리하는 도구

책임 있는 사용

연마는 의료 진단, 치료, 전문 코칭을 대체하지 않습니다. 통증, 질환, 부상 이력이 있거나 숨참기 훈련처럼 위험할 수 있는 활동을 할 때는 전문가의 조언과 안전한 환경을 우선해야 합니다.
