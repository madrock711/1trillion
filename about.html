연마 소개·작성·검증 정책

연마는 HPMPLab이 운영하는 브라우저 도구 프로젝트입니다. 핵심 영역은 클라이밍 힘 측정과 호흡 훈련 기록이며, 로컬 영상 제작과 무작위 조합 실험 도구를 별도 문서와 함께 제공합니다.

정책 최종 업데이트: 2026-07-26

누가 운영하고 작성하는가

HPMPLab은 연마의 프론트엔드 코드, 도구 동작, 안내 문서와 수정 이력을 한 저장소에서 함께 관리합니다. 공개 글의 작성자 표기는 HPMPLab으로 통일하고, 각 가이드에서 어떤 범위를 기능 검증했는지와 마지막 검증 날짜를 표시합니다.

연마는 의료기관, 전문 코칭 기관, 복권 판매·예측 서비스가 아닙니다. 전문 자격자의 검토를 받지 않은 글에는 이를 암시하는 표현을 쓰지 않으며, 의료 진단·치료·수익·당첨을 보장하지 않습니다.

왜 도구와 가이드를 함께 만드는가

타이머와 생성기는 버튼만으로도 실행할 수 있지만, 사용자는 기본값이 왜 정해졌는지, 숫자가 어떤 계산을 거쳤는지, 결과가 나오지 않는 조건은 무엇인지 알기 어렵습니다. 연마는 실행 화면과 독립 가이드를 분리해 조작 중에는 집중을 방해하지 않고, 검토할 때는 JS 없이도 방법과 한계를 읽을 수 있게 합니다.

좋은 기록은 값이 많다는 뜻이 아니라 같은 조건을 다시 확인할 수 있다는 뜻입니다. 그래서 도구마다 입력, 시간축, 단위, 데이터 출처와 저장 위치를 설명하고, 저울로 자세를 판별하거나 사진으로 발 치수를 자동 측정하는 것처럼 구현하지 않은 기능은 명확히 부정합니다.

현재 제공하는 여섯 가지 도구

  • 호흡 타이머: 들숨과 날숨 리듬을 시각/청각 신호로 따라가는 도구
  • CO2 테이블 타이머: 숨참기와 휴식 감소 패턴을 기록하는 도구
  • 아브라행 행보드 타이머: 저강도 로딩과 좌우 최대 힘 측정을 분리해 기록하는 도구
  • 암벽화 핏 점검: 좌우 발 실측값과 형태 자가 체크를 착화 질문으로 정리하는 도구
  • 시퀀스 생성기: 짧은 영상을 로컬 Canvas에서 PNG 스프라이트 시트로 바꾸는 도구
  • 로또 6/45 조합 생성기: 과거 데이터의 표시용 필터와 난수를 사용해 5개 조합을 만드는 오락용 도구

문서를 만드는 방법

  1. 코드 확인: 가이드의 시간, 단위, 계산식, 저장 범위를 실제 HTML·JavaScript 구현과 대조합니다.
  2. 근거 분리: 연구나 공식 문서에서 확인한 사실, 앱이 선택한 기본값, 기기 제약에서 추론한 값을 구분합니다.
  3. 재현 점검: 정상 흐름뿐 아니라 권한 거부, 샘플 부족, 파일 형식 오류, 연결 중단처럼 실패하는 조건을 확인합니다.
  4. 화면 확인: 데스크톱과 모바일에서 주요 콘텐츠, 키보드 포커스, 오류 상태와 링크를 점검합니다.
  5. 문서 동시 수정: 공개 기능이 바뀌면 관련 가이드와 변경 이력의 날짜도 실제 변경이 있을 때만 갱신합니다.

자동화 도구 사용 원칙

코드·문서 초안, 반복 검사와 형식 정리에 자동화 도구를 사용할 수 있습니다. 자동화 결과를 그대로 사실로 게시하지 않고, 저장소의 실제 코드·브라우저 동작·인용한 원문을 대조하는 검수 절차를 거칩니다. 자동화가 측정하지 않은 효과나 사용 경험을 만든 것처럼 서술하지 않습니다.

출처와 건강·안전 문구

외부 연구나 공식 자료를 활용하면 해당 문단 가까이에 원문 링크를 둡니다. 논문이 제시한 조건과 앱의 구현이 다르면 동일한 프로토콜이라고 표현하지 않습니다. 호흡·숨참기·손가락 로딩처럼 안전과 관련된 글은 불편·통증·어지러움 시 중단 기준과 도구가 대신할 수 없는 전문 판단을 함께 표시합니다.

로또 조합 글은 동행복권의 공식 확률을 기준으로 하며 과거 빈도, 앱 점수와 구간 패턴이 다음 회차의 당첨 확률을 높이지 않는다고 명시합니다.

정정과 문의

기능과 설명이 다르거나 링크·출처·회차 데이터에 오류가 있으면 문의 페이지로 화면, 브라우저, 재현 순서를 보내주세요. 확인 가능한 오류는 코드와 관련 문서를 함께 수정하고 최근 검증 목록에 남깁니다. 개인의 부상 진단, 의료 판단, 제품 구매 보증과 당첨 번호 상담은 답변 범위에 포함하지 않습니다.
